# Genesis MD+ for Analogue Pocket

Sega Genesis / Mega Drive core for the Analogue Pocket with **MD+ CD audio**
(MegaSD-style cue + wav soundtracks) and **save states (Memories)**.

Based on the [Analogizer Genesis core](docs/README_upstream.md) by RndMnkIII,
which is based on ericlewis' openFPGA Genesis core (a port of the MiSTer Genesis
core, itself derived from fpgagen). The Analogizer features stay enabled.

Version: **0.8.1**

## Features

- **MD+ CD audio**: MD+ patched ROMs play their CD-quality soundtrack straight
  from `.cue` + `.wav` files on the SD card. No conversion tool is needed.
  - 44.1 kHz 16-bit stereo WAV (including WAVE_FORMAT_EXTENSIBLE)
  - play once / loop, `REM LOOP` loop points, `REM NOLOOP`, fade, pause/resume,
    MD+ volume command
  - the first ~1.5 s of every track is cached in PSRAM in the background, so
    cached tracks start without delay
  - MD+ starts in the background right after the ROM is loaded; the game is
    never held
- **Save states (Pocket Memories)**: create and load Memories from the Pocket
  menu. The MD+ track resumes from the saved position after loading.
- Everything from the upstream core (Analogizer video/SNAC, SVP, mappers, ...).

## Installation

1. Copy the `Assets`, `Cores` and `Platforms` folders from the release zip to
   the root of the SD card.
2. Put the Genesis BIOS-free ROMs in `Assets/genesis/common/` as usual.

## Using MD+

1. Put the **MD+ patched ROM**, its **`.cue`** file and all **`.wav`** files in
   the same folder under `Assets/genesis/common/`.
2. Rename the `.cue` so it has the same name as the ROM:
   `Phantasy Star IV.md` -> `Phantasy Star IV.cue`.
3. Load the ROM from the Pocket menu. Normal ROMs (no matching `.cue`) run as
   usual; MD+ switches itself off.

Example:

```
Assets/genesis/common/PS4/
  Phantasy Star IV.md      (MD+ patched)
  Phantasy Star IV.cue
  Phantasy Star IV 01.wav
  Phantasy Star IV 02.wav
  ...
```

Menu **MD+ Audio**: `On 100%` / `75%` / `50%` / `25%` / `Off` (applies on the
next ROM load).

Notes
- Use an MD+ patch made for the exact ROM revision you have. Translated ROMs
  usually need a patch made for that translation.
- Right after a game starts, the Pocket answers the core's SD requests slowly
  for several seconds, so the very first track can start late. Commands sent
  before MD+ is ready are queued and played as soon as it is ready.
- The SRAM window is limited to 0x200000-0x2FFFFF (MD+ patches put their driver
  at 0x300000 and above).

## Save states

- Pocket menu -> Memories -> create / load.
- The state is taken on the next vertical blank by a small 68000 routine, so a
  game must have its vblank interrupt enabled (all normal gameplay does).
- Limitations
  - Virtua Racing (SVP) is not supported (the core reports it to the Pocket).
  - Battery save RAM is not part of the state (your in-game saves are kept).
  - FM notes that are held at the moment of saving may cut out briefly after
    loading.

## Known issues

- Tested mainly with Phantasy Star IV (MD+ patch).
- The menu option "M30 Controllers" from the upstream core was removed to make
  room for the MD+ menu.

## Building

Quartus Prime Lite 25.1 (Cyclone V 5CEBA4F23C8). Open `src/fpga/ap_core.qpf`
and compile. Reverse the bit order of each byte of `output_files/ap_core.rbf`
to make `bitstream.rbf_r`. See [docs/TECHNICAL.md](docs/TECHNICAL.md) for the
design.

The 68000 save state routine is generated by `tools/ss_handler.py`
(`python3 tools/ss_handler.py src/fpga/core/rtl/ss_hrom.sv`).
